## 本版改动

修订版在初稿的基础上，按科学准确、事实可查、便于生活三条做了以下改动。

| 篇 | 改动 |
|---|---|
| 01 | 补东方健康膳食模式，作为中国读者的对照；四类研究压成一张表；补一段人群研究在什么情况下可信，避免读者把人群研究一概否定；两个类型化的例子改为「常见的情形」，真实事例指向第 09 篇 |
| 02 | 速读里「共同点是亚油酸多」改为「多数亚油酸含量高」；补溶剂与精炼一节，回应初稿里没有回应的溶剂理由；承认反方说对的两处，亚油酸多的油反复油炸更易氧化、老试验数据没有完整发表；删去悉尼试验人造黄油含反式脂肪的未核实说法；新增油桶标签一节；要点速查改为「减少饱和脂肪护心」 |
| 03 | 补国际癌症研究机构与 NutriRECS 结论分歧的原因；补孕期吃肝各国建议不同、喝茶影响铁吸收两条提示；takeaway 写明对个人的绝对获益不大 |
| 04 | 删去所引研究不支持的一句；新增三餐的蛋白质一节，补中式早餐的缺口和老人好嚼的食物；资助来源一节压缩 |
| 05 | 删去未核实的个体减重数字；新增轻断食一节，引用国内团队 2022 年的随机试验；补外卖主食的选法 |
| 06 | 新增代糖一节，写世卫组织 2023 年代糖指南和阿斯巴甜 2B 类；含糖饮料的替代顺序改为白水、淡茶在前；补现制饮品「无糖」的提醒 |

| 09 | 删去 Truemed 一例，压缩美国新指南的内容；补国内权健案作为保健品营销的例子；全系列速查移到第 10 篇 |
| 10 | 新增，讲减盐、含糖饮料、限酒、反式脂肪、蔬菜水果和全谷物，引用国内低钠盐随机试验，收尾放全系列速查 |
| 全部 | 要点速查的证据描述统一为四种，有随机试验、人群研究多且结果一致、人群研究结果不一致、主要是动物实验或推测；「适合怎么做」改为「可以怎么做」；行动清单第一条改为当天就能做的小事 |

## 系列设定

| 项 | 设定 |
|---|---|
| 系列名 | 吃的证据。备选「为腹不为目」，取自《道德经》第十二章，贴切与否由作者定 |
| 读者 | 在小红书、短视频上看到各种饮食说法、关心饮食和皮肤的普通读者，兼顾「医美选择」现有读者 |
| 载体与篇幅 | 微信公众号十篇，每篇正文约 1650 至 2500 个汉字，按全部字符计约 2000 至 3000 字；开头速读摘要 200 至 300 字 |
| 篇章 | 速读、先说结论、分节正文、要点速查、行动清单、下一讲，篇末为注、参考文献和署名 |
| 作者口吻 | 从业者口吻；营养和临床判断写成指南和研究怎么说、该问哪个科；作者自己判断的只有证据类型与商业利益 |
| 证据描述 | 有随机试验、人群研究多且结果一致、人群研究结果不一致、主要是动物实验或推测，个别条目按实际写专家共识或法律规定 |
| 统一用词 | 种子油、加工肉、新鲜红肉、超加工食品、代糖、随机对照试验（首次全称，之后写随机试验）、队列研究、相对风险、绝对风险 |
| 外文机构 | 正文只保留世卫组织、国际癌症研究机构、美国国家科学院、欧盟等读者熟悉的名称，其余写进篇末的注 |
| 配图 | 封面用 2.35:1 氛围图；正文未配信息图，第 02 篇的油脂表可在核实数值后改画成图 |

## 发布顺序与推送素材

按编号每周发一篇，十周发完。如果发在「医美选择」同一个号，建议把第 08 篇提到第二篇发，其余顺延，各篇的「下一讲」随顺序改写。推送标题沿用主副标题，摘要按微信后台 120 字以内写成。

| 篇 | 推送标题 | 推送摘要 |
|---|---|---|
| 01 | 吃的证据 · 一条营养说法要问的四件事 | 同时戒红肉、戒种子油，能吃的越来越少。两条禁令来自对立的两派。判断任何饮食说法，先问换成了什么、吃多少、绝对风险多大、说话的人卖什么。 |
| 02 | 种子油之争 · 菜籽油、花生油与亚油酸 | 种子油有毒的人体证据弱，反方也有说对的地方。家里的油要不要换，先管用油总量和反复油炸，再看懂油桶上的品种、工艺和转基因标示。 |
| 03 | 两类红肉 · 加工肉与新鲜红肉的证据差别 | 加工肉致癌证据较硬，但一生中的绝对风险增加不到一个百分点；新鲜红肉证据弱。不吃红肉的育龄女性要补铁，喝茶要和正餐错开。 |
| 04 | 蛋白质热 · 每公斤 1.2-1.6 克适合谁 | 美国新指南把蛋白质建议提到每公斤 1.2 到 1.6 克，我国女性推荐每天 55 克。力量训练者和老人多吃有依据，普通人吃够即可，缺口多在早餐。 |
| 05 | 碳水与减重 · 低碳、生酮、轻断食与不吃主食 | 不吃主食头两周掉的多是水，一年后低碳水、轻断食和普通控制热量减重相当。用降糖药的人改饮食前先问医生。 |
| 06 | 超加工食品 · 糖、代糖、零食与外卖 | 超加工食品与多种慢性病相关，原因未明；含糖饮料证据较硬。代糖饮料只作过渡，阿斯巴甜 2B 类说的是证据确定性，普通人不必戒麸质。 |
| 07 | 转基因食品 · 安全性、黄金大米与非转基因标签 | 已获批转基因食品的安全性证据较充分，黄金大米事件是研究伦理违规。花生油、橄榄油标「非转基因」不带有用信息，2018 年起已被禁止。 |
| 08 | 以食养颜 · 抗糖丸、口服胶原与牛油护肤 | 口服胶原只看非企业资助的研究，效果就看不到了；抗糖丸和牛油护肤缺少人体证据。普通食品不能宣称疾病预防和治疗功能。 |
| 09 | 资助与结论 · 营养研究的钱从哪里来 | 企业资助的研究更容易得出有利于产品的结论，利益两边都有。看一项营养研究，先看资助声明，再找公共资金做的研究对照。 |
| 10 | 盐糖与酒 · 证据站得住的几件事 | 证据站得住的几件事是减盐、少喝含糖饮料、限酒、避开反式脂肪、蔬果全谷吃够。中国农村两万人的试验里，低钠盐让卒中少了 14%。 |
