## 系列设定

| 项 | 设定 |
|---|---|
| 系列名 | 吃的证据。备选「为腹不为目」，取自《道德经》第十二章，贴切与否由作者定 |
| 读者 | 在小红书、短视频上看到各种饮食说法、关心饮食和皮肤的普通读者，兼顾「医美选择」现有读者 |
| 载体与篇幅 | 微信公众号，每篇正文约 1500 至 2200 个汉字，按全部字符计约 1800 至 2600 字；开头速读摘要 200 至 300 字 |
| 篇章 | 速读、先说结论、分节正文、要点速查、行动清单、下一讲，篇末为注、参考文献和署名 |
| 作者口吻 | 从业者口吻；营养和临床判断写成指南和研究怎么说、该问哪个科；作者自己判断的只有证据类型与商业利益 |
| 证据表述 | 正文写研究类型、人数、结果是否一致、差别多大；要点速查的证据一列用三种写法，有随机试验、只有人群研究、主要是动物实验或推测，个别条目按实际情况写专家共识或法律规定 |
| 统一用词 | 种子油、加工肉、新鲜红肉、超加工食品、随机对照试验（首次全称，之后写随机试验）、队列研究、相对风险、绝对风险 |
| 外文机构 | 正文只保留世卫组织、国际癌症研究机构、美国国家科学院、欧盟等读者熟悉的名称，其余写进篇末的注 |
| 配图 | 封面用 2.35:1 氛围图；本版正文未配信息图，第 02 篇的油脂表可在核实数值后改画成图 |

## 发布顺序

按编号每周发一篇，九周发完。如果发在「医美选择」同一个号，建议把第 08 篇提到第二篇发，先用读者熟悉的皮肤话题接上这个系列，其余顺延；各篇的「下一讲」随顺序改写。

## 写作规范自检

九篇正文按 tools/lint.mjs 自检，error 为 0；剩余的 warn 是标准名称里的「成分」两字（《中国食物成分表》、营养成分表），属于专有名称，保留。自检脚本只能查出形式问题，有没有替读者标注感受、删掉一句信息少没少，仍要逐句读。
