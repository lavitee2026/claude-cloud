医美选择 · 网站部署说明

一、包里有什么

  医美选择网站/      网站本身，81 个页面，全部是静态文件
    index.html        首页
    404.html          页面不存在时显示
    a/  c/  g/        篇目、子分类、导读页
    assets/           样式、脚本、搜索索引、站点图标
    og/               每页的分享卡片图
    set-domain.py     确定域名后运行一次，补上规范网址、分享图地址和站点地图
    sitemap.json      站点地图的数据，set-domain.py 会读取
  部署说明.txt        本文件

二、最快的部署方式

  把「医美选择网站」文件夹里的全部内容，原样上传到网站的根目录（或任意子目录），打开 index.html 所在的网址即可。
  页面之间都是相对链接，放在根目录或子目录都能用，不需要数据库，也不需要后端程序。
  搜索功能会读取 assets/search-index.json，需要通过网址访问；直接双击本地的 html 文件打开时，其他页面都能看，搜索不能用。

三、确定域名以后（建议做）

  在网站目录里运行：
    python3 set-domain.py https://你的域名/
  部署在子目录时，网址带上目录，例如 https://www.example.com/yimei/
  运行后每页会补上规范网址和分享卡片图的完整地址，并生成 sitemap.xml、更新 robots.txt。
  可以在上传前在本机运行，也可以上传后在服务器上运行；换域名时再运行一次。
  不运行也不影响网站的浏览和搜索，只是搜索引擎和社交平台拿不到完整地址。

四、常见托管方式

  Nginx：把文件放到站点目录，配置里加上
      location / { try_files $uri $uri/ =404; }
      error_page 404 /404.html;
    部署在子目录时，把 404.html 的路径改成子目录下的路径。
  对象存储（阿里云 OSS、腾讯云 COS 等）：开启静态网站托管，默认首页填 index.html，默认 404 页填 404.html。
  GitHub Pages、Cloudflare Pages、Netlify：直接上传这个文件夹，或者把它放进仓库作为发布目录。

五、需要注意

  在中国大陆的服务器或对象存储上用自有域名对外提供访问，需要先完成 ICP 备案。
  请保持文件夹结构不变，不要只上传部分文件，页面之间的链接依赖这个结构。
  内容更新时，在源仓库运行 npm run package 重新打包，用新包整体覆盖旧文件。
